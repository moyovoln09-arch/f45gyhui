# Proxy Tester

Скрипт для тестирования и ранжирования прокси-ссылок VLESS, Trojan и Hysteria2 на Linux.

## Особенности
- **Поддержка протоколов:** VLESS, Trojan, Hysteria2.
- **Многофакторное тестирование:**
  - Доступность популярных веб-сайтов и средняя задержка.
  - Скорость загрузки видео с YouTube (используется `yt-dlp`).
  - Скорость загрузки через Torrent (используется `aria2c`).
- **Ранжирование:** Автоматический расчет оценки (score) на основе стабильности и скорости.
- **Экспорт в Sing-Box:** Генерация готового клиентского конфига с лучшими нодами.
- **Рандомизация:**
  - Перемешивание входных ключей перед тестом.
  - Случайный порядок нод в экспортированном конфиге (скрывает реальный ранг и уменьшает нагрузку на первый сервер).
  - Наличие балансировщика нагрузки (`loadbalance`) и автоматического выбора по задержке (`urltest`).

## Требования
- Python 3.8+
- [sing-box](https://github.com/SagerNet/sing-box) в `$PATH`
- [aria2c](https://aria2.github.io/) (для торрент-тестов)
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) (для тестов YouTube)

## Установка
```bash
# Клонируйте репозиторий или скачайте скрипт
chmod +x proxy_tester.py
# Попробуйте автоматическую установку зависимостей
./proxy_tester.py --keys keys.txt --auto-install
```

## Использование
```bash
./proxy_tester.py --keys list.txt --export-singbox config.json --top 10
```

### Основные аргументы:
- `--keys`: Путь к файлу со ссылками (по одной на строку).
- `--top`: Количество лучших нод для вывода и экспорта (по умолчанию 5).
- `--export-singbox`: Путь для сохранения конфига Sing-Box.
- `--shuffle`: Перемешать список ключей перед началом теста.
- `--no-shuffle-output`: Отключить перемешивание нод при экспорте (сохранить порядок по рейтингу).
- `--auto-install`: Попытаться установить системные зависимости (`sing-box`, `aria2c`, `yt-dlp`).

## Hysteria2
Для Hysteria2 рекомендуется настройка 200 Mbps (`up_mbps=200`, `down_mbps=200`), которая установлена по умолчанию. Это обеспечивает отличную производительность в играх. Скрипт поддерживает параметры `sni`, `insecure`, `obfs` и `obfs-password`.
